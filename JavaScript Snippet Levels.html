01

Click a button and do something

Easy

The basic pattern behind every interactive page: find an element, listen for an event, then change something on the screen.

  • querySelector()
  • addEventListener('click')
  • textContent
  • classList.toggle()
  • input.value
level 1 of 5
button-clicks.html

Try it

  • Add a −1 button. How do you stop the count from going below 0?
  • Make the number turn orange once the count reaches 5.
  • Pressing Enter also greets you. Find the line that makes that happen.
02

React to posts with likes and emoji

Easy to medium

One click listener on the whole feed handles every post. Each person gets one reaction per post: click it again to remove it, or pick another to switch.

  • event delegation
  • event.target.closest()
  • data-* attributes
  • toggle state
  • aria-pressed
level 2 of 5
reactions.html

Try it

  • Copy a fourth post into the HTML. Do you need to change the JavaScript? Why not?
  • Add a ❤️ reaction button to every post.
  • Show the total number of reactions under each post.
03

Add to cart

Medium

Products live in an array, not in the HTML. JavaScript draws them, and one renderCart() function redraws the cart every time something changes. Product photos come free from Unsplash and load in students' own browsers; this preview shows drawn stand-ins.

  • arrays of objects
  • map().join('')
  • find()
  • filter()
  • reduce()
  • render function
level 3 of 5
add-to-cart.html

Try it

  • Add a new product by editing only the products array.
  • Limit each item to a maximum of 5 in the cart.
  • Show "You get free shipping!" when the total reaches ₱500.
04

Checking out

Medium to hard

A checkout form that checks every field, recalculates the total when the delivery option changes, accepts promo codes (try STUDENT10 or LESS50), and prints a receipt.

  • submit + preventDefault()
  • regex validation
  • radio buttons
  • computed totals
  • escaping user input
level 4 of 5
checkout.html

Try it

  • Add a FREESHIP promo code that makes shipping free.
  • Disable Express delivery when the subtotal is under ₱200.
  • Why does the receipt use escapeHTML() on the name? Type <b>Ana</b> and see.
05

Mini shop that remembers the cart

Hard

Everything together: search, category filters, sorting, stock limits, a slide-in cart, a checkout dialog and toast messages. The cart is saved in localStorage, so it survives a page refresh. Photos load from Unsplash when the code runs on its own; this preview shows drawn stand-ins.

  • one state object
  • filter + sort
  • localStorage
  • JSON.stringify / parse
  • <dialog>
  • debounce
